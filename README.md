# m4s 批处理工具

Windows 下基于 Qt Widgets (C++17, qmake) 的桌面工具，用于批量处理 m4s 音视频文件。

## 功能
- 添加多个目录（支持「添加目录」按钮多选，或拖拽文件夹到窗口）。
- 每个目录需包含：
  - 视频文件：`*_0.m4s`
  - 音频文件：`*_1.m4s`
  - 元数据：`.video.json`（含 `title` 字段）
- 解密：流式跳过 m4s 文件开头的 6 个字节（分块读写，支持大文件）。
- 生成 MP4：调用外部 `command`（占位，见 `mp4builder.cpp`）。
- 生成 MP3：将解密后的音频复制/重命名为 `title.mp3`。
- 输出目录结构：`输出根目录/title/`（存放 mp4、mp3；解密临时文件在系统临时目录）。
- 列表显示「选择 / 目录 / 标题 / 状态 / 操作」，勾选后点击「生成 MP4」「生成 MP3」串行处理选中项。
- 后台线程串行执行，不并行占用资源；支持「停止」。

## 构建
需要安装 Qt（含 qmake，Qt5 或 Qt6 均可）。

```bash
qmake bilibili-tool.pro
make            # 或 nmake / jom（Windows）
```

Visual Studio 用户也可通过 `qmake -tp vc` 生成 vcproj。

## 使用步骤
1. 选择输出根目录。
2. 添加目录（按钮或拖拽）。
3. 勾选要处理的任务（表头「全选」可批量勾选）。
4. 点击「生成 MP4」或「生成 MP3」。
